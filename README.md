# Sablewood — サブルウッド

朽ちた森を潜る、ターン制の生存RPG。ブラウザで動く単体アプリで、外部画像・音声アセットを一切使っていません。スプライトも効果音もすべてコードで生成しています。

```
npm install
npm run dev      # http://127.0.0.1:5178
npm run build    # dist/ に静的出力
npm test         # ロジックの単体テスト
npm run verify   # 実Chromeでの自動プレイ検証
```

## 遊び方

ソーンベリ村から南の階段を降り、20層の底を目指します。4層ごとに主が待ち受けます。

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印 / テンキー |
| 調べる・階段 | E / Space |
| 持ち物 | I |
| 能力値 | C |
| 依頼 | J |
| 技 | 1〜8 |
| 待機 | . |
| 村で休む | R |
| メニュー | ESC |

## 中身

- **ターン制戦闘**: 命中・回避・会心・属性（炎/毒/氷）・状態異常（毒/炎上/出血/鈍足/再生/激昂/防御）
- **成長**: 経験値によるレベルアップ、能力ポイントの手動割り振り、レベルで解放される10種の技
- **装備**: 6スロット（武器/体/頭/盾/指輪/護符）、接頭辞・接尾辞によるランダム生成、鍛冶による強化（最大+5）
- **経済**: 村の商店で売買、依頼の報酬、宝箱、敵のドロップ
- **世界**: シード固定の procedural 生成。村と20層のダンジョン、視界計算（FOV）、到達性の自動除去
- **演出**: 画面振動・ヒットストップ・ダメージ数値・パーティクル・松明の明滅・昼夜
- **描画**: すべて Canvas 2D のピクセルアート。画像ファイル0枚
- **音**: Web Audio による効果音合成。音声ファイル0個

## 検証

`npm run verify` は実 Chrome を CDP で操作し、40項目を確認します。

- 起動・タイトル・新規開始
- キャンバスの実描画（輝度分散・色数・中央領域の標準偏差）
- HUD・HPバー・ミニマップ・技スロット
- 移動・持ち物画面・ESC
- ダンジョン生成・敵の出現・実際の戦闘での撃破
- レベルアップ・能力ポイント・技の解放
- 技の使用と気力消費、状態異常の付与
- セーブの直列化・往復・階層の記録
- 売買による所持金の増減
- 依頼の進捗
- 260ターン連続実行
- 20層までの降下
- 死亡・セーブ消去・死亡画面
- 全行程での未捕捉例外とコンソールエラーが0件

結果は `verification/` にスクリーンショットとして残せます（`node tools/verify.mjs --shots`）。

## 構成

```
src/
  core/      rng, types, game（シミュレーション本体）
  data/      items, enemies, skills
  world/     mapgen（村・ダンジョン・FOV）
  render/    art（スプライト生成）, render（カメラ・光・演出）
  audio/     sfx（Web Audio 合成）
  ui/        hud, screens
tests/       単体テスト（21件）
tools/       verify.mjs（ブラウザ検証）
```

ゲームロジックは DOM に依存しないので、`tests/` から直接動かせます。
